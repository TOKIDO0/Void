## 3. 全局开发硬约束

- 始终围绕 VOID，不得使用 ZERO-ONE 或其他旧名称。
- 第一阶段只做 Web MVP，不直接做桌面打包；正式产品方向是电脑端可安装 Agent，手机端不进入当前路线。
- 大模型默认使用云端 API，用户自己配置 API Key、Base URL、模型名和请求 JSON。
- VOID 是本地运行、本地存储的去中心化 Agent，不代表本地部署大模型。
- 代码必须模块化，前端、模型适配、记忆、语音、健康档案、唤醒策略必须分层。
- 前端组件来源限制为 Ali Imam Registry：`https://aliimam.in/docs/registry`。不得随意混用多个组件库。
- 动效主线使用 GSAP，React 项目优先使用 `@gsap/react` 的 `useGSAP`。
- 不写测试代码，除非用户明确要求。

## 4. 推荐开发顺序

1. Web 静态界面：黑底、Blob 主体、底部胶囊。
2. 前端状态机：idle / listening / thinking / speaking。
3. 动效系统：Blob 状态响应、胶囊变形、声波可视化。
4. 模型配置页：支持 OpenAI-compatible、Anthropic 等 Provider 配置。
5. 文本对话链路：先跑通输入、LLM 回复、状态切换。
6. 语音链路：STT、TTS、主动监听、唤醒判断。
7. 本地记忆：用户画像、偏好、健康档案、长期目标等分区。
8. 健康档案和安全边界。
9. Tauri 或其他桌面容器适配，进入电脑端可安装应用。
